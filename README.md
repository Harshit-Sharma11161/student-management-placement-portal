# Student Management & Placement Portal

A full-stack web application for managing student profiles, placement opportunities, job applications, and application status.

## 🚀 Features

### 👨‍🎓 Student

- Student registration and login
- JWT-based authentication
- Student profile management
- Academic information management
- Skills and project information
- Resume information
- Browse available placement jobs
- View job details and eligibility
- Apply for jobs
- Prevent duplicate job applications
- View submitted applications
- Track application status

### 👨‍💼 Admin

- Admin authentication
- Role-based access control
- Admin dashboard
- View all student applications
- View student information
- Update application status
- Create placement jobs
- Edit jobs
- Delete jobs
- Open/close job opportunities
- View placement statistics

## 🛠️ Tech Stack

### Frontend

- React.js
- Vite
- JavaScript
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
